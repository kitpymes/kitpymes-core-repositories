# v.2.0.0
Versión mayor: rompe a quien venga de la 1.x. Abajo, qué cambia y cómo migrar.

- Requiere .NET 10 o superior (la 1.0.2 era .NET 5).
- PagedOptions incorpora Properties para indicar por qué campos ordenar.
- El código pasa a github.com/kitpymes/kitpymes-core-repositories y el paquete se publica desde GitHub Actions.

## Cambios incompatibles y cómo migrar desde 1.x

- Find(key) y FindAsync(key) -> GetByKey(params object[] keyValues) y GetByKeyAsync(...): admiten claves compuestas.
- GetOne(...) y GetOneAsync(...) -> Get(...) y GetAsync(...): devuelven null si no hay resultado.
- GetPaged(...) y GetPagedAsync(...) -> GetAllPaged(...) y GetAllPagedAsync(...).
- En los repositorios relacionales (IQueryRelationalRepository) cambian igual GetOne y GetPaged.
